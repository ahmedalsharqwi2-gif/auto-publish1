# مؤثرات science-discovery-shorts

حزمة مؤثرات غير موسيقية لمقاطع العلوم والاكتشافات:

- `science_discovery_sting.mp3`: كشف معلومة أو نتيجة مهمة.
- `science_transition_whoosh.mp3`: انتقال سريع بين اللقطات.
- `science_lab_ambience_loop.mp3`: جو مختبر/مرصد هادئ قابل للتكرار تحت السرد.

يضيف مسار التجميع هذه المؤثرات تلقائيًا: جو المختبر عند `0.055`، والـwhoosh والـsting عند `0.18`، مع limiter نهائي `-0.45 dBFS` حتى يبقى السرد هو العنصر المسيطر. لا توجد موسيقى خلفية.

سرعة الراوي تُضبط من `EDGE_TTS_RATE` في workflow؛ القيمة الحالية `-15%` مع الصوت `ar-EG-ShakirNeural` والنبرة `-2Hz`. غيّرها تدريجيًا بين `-10%` و`-18%` فقط، ثم راجع مدة الصوت وتزامن الترجمة.
